Steel plates.

— DART System

Targets that move.

A mesh of motorized, sensor-instrumented nodes orchestrated from a tablet. Every shot logged, every drill scripted, every node wireless.

  • B1Servo-driven face-on / edge-on / pivot motion
  • B2Piezo hit-detection — <40 ms to score
  • B3Per-shot telemetry exported to CSV / JSON
  • B4Drop-and-play — provisioned in 60 seconds
/ 02

An RTOS-grade network — on a range.

Wireless mesh,
real-time firmware,
tablet command.
T+0 ms

Round impacts the plate.

A piezoelectric film bonded behind the AR500 face picks up the shock wave from the round.

Sensor layer
T+4 ms

MCU classifies the event.

Zephyr RTOS on the nRF52840 filters, de-bounces, and rejects wind and vibration noise via an IMU gate.

Firmware
T+22 ms

Hit hops through the mesh.

A vendor BLE Mesh message travels neighbor-to-neighbor to the provisioner. TTL 5, redundant paths.

RF Fabric
T+38 ms

Tablet scores & reacts.

Score updates on the Range Console. Scripted drills cue the next engagement — servos pivot, LEDs flash.
